# FP&A Financial Analysis Projects

FP&A projects centered on budgeting, forecasting, Variance Analysis & Dashborad. These projects modeled corporate finance processes for business analysis.

**Projects Included:**

Annual Budget Model: Created a financial budget for a full year projecting revenues, COGS, OpEx, & EBITDA and profitability for key segments of a business.

Forecasting and Scenario Analysis: Created financial forecasts and scenarios to analyze revenue growth changes of ±10-15% and cost changes.

Variance Analysis: Analyzed budget vs. actuals to identify key financial variances and performance drivers.

FP&A Dashboard: Created a financial dashboard to summarize key performance indicators, revenue growth, and key performance metric

**Key Skills:**

Financial Planning and Analysis | Budgeting | Forecasting | Variance Analysis | Financial Reporting | Excel Modeling
